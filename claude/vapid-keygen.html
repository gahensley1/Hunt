VAPID keypair

Generated by your own browser, offline, using the Web Crypto API. Nothing is sent anywhere — you can disconnect from the network first and it will still work. This page is not part of the app and never ships.

The private key is a secret. It goes into Cloudflare as a Worker secret and nowhere else. Never into index.html, never into SUPER-HANDOFF.md (that file is world-readable), never pasted into a chat. Only the public key is safe to share.

Public key — safe to share

Paste this one to Claude. It is embedded in the app and visible to anyone anyway.

VAPID_PUBLIC

Private key — secret

Cloudflare dashboard → your Worker → Settings → Variables → Add secret, named VAPID_PRIVATE. Paste it there, then close this page.

VAPID_PRIVATE — do not share
