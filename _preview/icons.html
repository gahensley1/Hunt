App icon — the options

Every icon below is shown as the stores actually mask it: iOS rounds the corners, Play crops to a circle. Anything important near an edge gets cut. The dark strip shows them on a home screen at real size.

A — what ships today

hunt-icon-v5.png — 180×180 only. Referenced by the existing apple-touch-icon link. Too small for either store: Apple wants 1024, Play wants 512.

B — option C set

art/icon-C/ — ships 1024, 512 and 180 already, plus an Android adaptive pair. The only set that is store-complete.

C — option C, Android adaptive

Foreground composited over background, as Android does it. The separate layers let the launcher animate and mask them — Play’s preferred format.

D — Bonnie source

art/bonnie-icon-source.png, 989×989 — the artwork the option-C set was derived from. Included so you can see the source against its crops.
